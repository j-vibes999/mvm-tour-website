# MVM Group — Explore Laos

เว็บไซต์ท่องเที่ยวลาว 4 ภาษา: ไทย ลาว อังกฤษ และจีนตัวย่อ คงหน้าแรกที่เน้นภาพและจุดหมาย พร้อมค้นหา เก็บสถานที่ และเตรียมข้อความสอบถามทริป

เปิดเว็บในเครื่องจากโฟลเดอร์นี้:

```sh
npm ci
npm run dev
```

เปิด `http://127.0.0.1:4173/` เพื่อเลือกภาษาตามเบราว์เซอร์อัตโนมัติครั้งแรก (หากไม่รองรับใช้ภาษาอังกฤษ) ปุ่มภาษาในส่วนหัวเปิด dropdown เดียว และจำภาษาที่เลือกเองไว้ในเครื่อง ลิงก์ `/th/`, `/lo/`, `/en/` หรือ `/zh/` เปิดภาษานั้นโดยตรง กด Ctrl+C ใน Terminal เพื่อหยุด
ต้องมี Node.js พร้อม npm

หรือดับเบิลคลิก `เปิดเว็บ.command` ระบบจะติดตั้งไฟล์ที่จำเป็นหากยังไม่มี สร้างเว็บจากต้นฉบับล่าสุด แล้วเปิดเบราว์เซอร์ให้อัตโนมัติ โดยเสิร์ฟจาก `build/` และรองรับ URL ลึกทั้งสี่ภาษา หากพอร์ต 4173 มีเว็บอื่นใช้อยู่จะเลือกพอร์ตว่างถัดไป และใช้เซิร์ฟเวอร์เดิมซ้ำเฉพาะเมื่อยืนยันว่าเป็นโปรเจกต์นี้

`npm run dev` ใช้เซิร์ฟเวอร์ Node.js เดียวกัน หรือรัน `node scripts/serve-local.mjs --no-open` หากต้องการเปิดเบราว์เซอร์เอง

- แก้เนื้อหาต้นฉบับใน `dist/content.js` และไฟล์ UI ใน `dist/`
- `npm run build` สร้างเว็บพร้อมโฮสต์ใน `build/` รวม 502 หน้า; อย่าแก้ไฟล์ใน `build/` โดยตรง
- หลังแก้ต้นฉบับให้รัน build ใหม่แล้วรีโหลดเบราว์เซอร์ หรือเริ่ม `npm run dev` ใหม่
- `SITE_URL=https://your-actual-domain.example npm run build` ใช้กำหนดโดเมนจริงสำหรับ canonical, รูปแชร์ และ sitemap; ค่าเริ่มต้นใช้โดเมน Sites เดิมของโปรเจกต์
- เว็บสร้าง URL แยกทั้ง 4 ภาษา ใช้ `zh-Hans` สำหรับ metadata ภาษาจีน และยังเปิดลิงก์เก่าแบบ `#/...` ได้

ข้อมูลจริงที่ต้องใส่ก่อนรับลูกค้า: ช่องทางติดต่อ, ข้อมูลบริษัท/ทีม, ราคาและบริการยืนยัน โปรแกรมทั้งหกปัจจุบันยังเป็นตัวอย่าง ไม่มีการรับจองหรือชำระเงินออนไลน์ รายละเอียดที่ลูกค้ากรอกเพื่อเตรียมข้อความไม่ถูกส่งหรือเก็บบนเซิร์ฟเวอร์
