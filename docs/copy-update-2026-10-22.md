# ปรับภาษาและช่องข้อมูลจริง — 22 ตุลาคม 2026

ปรับตาม `docs/copy-audit-2026-10-21.md` และข้อเสนอที่อนุมัติใน `docs/claude-work-verification-2026-10-22.md` โดยคงข้อมูลท่องเที่ยว ตัวเลข ชื่อสถานที่ ราคาและสถานะตัวอย่าง ตลอดจนเงื่อนไขการเดินทางที่เกี่ยวข้อง

## ข้อความที่ปรับแล้วในข้อมูลและคลังภาษา

- ไทย: เปลี่ยน “พักช้า” เป็น “พักผ่อนสบาย ๆ” และใช้ชื่อ “วังเวียงและอ่างเก็บน้ำน้ำงึม” ตรง ๆ ตัดคำกล่าวกว้างในคำบรรยายถ้ำกองลอ โดยคงระยะทางราว 7.5 กิโลเมตร
- หน้าแรก: คำบรรยายหนองเขียวบอกแม่น้ำอูและภูเขาหินปูนโดยตรง ภาษาอังกฤษใช้ “Outdoor activities” เป็นชื่อหมวด กิจกรรมและคำบรรยายอื่นที่สื่อชัดอยู่แล้วคงไว้
- โปรแกรมทั้ง 6 ชุด: เกลา 10 สรุปรายวันและข้อความกิจกรรมที่สะดุด ให้เริ่มด้วยสถานที่/กิจกรรมก่อนเงื่อนไข ลด “พิจารณา / consider” ที่ซ้ำต่อเนื่อง โดยคงเวลาเดินทางถึง การเปิดทาง ความพร้อมร่างกาย ทางชัน การต่อรถ/เรือ และจุดส่งที่ต้องตกลง ข้อความตักบาตรและความเคารพต่อประเพณียังคงเดิม
- ราคา: ใช้คำอธิบายราคาตัวอย่างต่อท่านสำหรับวางแผน และระบุว่าจำนวนผู้เดินทางกับบริการที่รวมในราคาต้องยืนยันในใบเสนอราคา ตัวเลข สกุลเงิน และสถานะ `example` ไม่เปลี่ยน
- ลาว: แก้ลำดับคำในข้อควรระวังทางลื่น ใช้ข้อความที่สื่อถึงลมนิ่งในบริบทบอลลูน และอธิบายการปรับแผนเดินทางทางเรือให้ชัดว่าเป็นความยืดหยุ่นของผู้เดินทาง
- จีน: ลดการแปลโครง “Home of” ตรงตัว ระบุผู้เดินทางในรายการ “เหมาะกับใคร” ลดคำขยายเกินจำเป็น และใช้ “在河畔，慢下来” ในการ์ดริมน้ำ
- อังกฤษ: ใช้ `travellers` ตามการสะกดของ UI เดิม และเกลาประโยคกิจกรรมหลังเดินทางถึงวังเวียง
- คงคีย์อังกฤษเดิมทุกคีย์ไว้ พร้อมเพิ่มคีย์ฉบับแก้และคำแปลลาว/จีนที่ตรงกัน เพื่อให้ไฟล์ UI ที่รวมงานตามลำดับยังทำงานได้

## รายการแทนข้อความในไฟล์ UI

`.artifacts/fix-2026-10-22/copy-ui-replacements.json` มีรายการ `{file, old, new}` แบบ literal 13 รายการ สำหรับผู้รวมงานใช้กับ `dist/app.js` และ `dist/ui-kit.js` หลังเจ้าของไฟล์ส่งคืนงาน ไม่ได้แก้ไฟล์เหล่านั้นในงาน copy นี้

รายการครอบคลุมป้ายราคา หัวแบบฟอร์ม ป้ายรายการที่เลือก ปุ่มสร้างข้อความสอบถาม ปุ่มดูรายละเอียดสถานที่ คำโปรย hero และหัวชวนเริ่มวางแผนกับ MVM Group คำแปลของทั้งคีย์เดิมและคีย์ใหม่พร้อมแล้วใน `dist/locales/ui.js`

## ช่องข้อความต้อนรับจริง

เพิ่ม `companyProfile.ownerData.welcome` ใน `dist/content.js` เป็นข้อมูลว่างดังนี้:

```js
welcome: {
  message: { th: '', lo: '', en: '', zh: '' },
  name: { th: '', lo: '', en: '', zh: '' },
  role: { th: '', lo: '', en: '', zh: '' },
  image: '',
},
```

เจ้าของบริษัทเติมข้อความที่อนุมัติ ชื่อจริง ตำแหน่งจริง และภาพที่ได้รับอนุญาต รักษาฟิลด์ทั้ง 4 ภาษาให้ครบ การแสดงผล Home/About ใช้ `welcomeHtml` ร่วมกันโดยผู้รวมงานเชื่อมต่อให้ และซ่อนเมื่อข้อความภาษาปัจจุบันว่าง ไม่มีการสร้างชื่อผู้ก่อตั้ง ประวัติ ใบอนุญาต รีวิว หรือข้อมูลติดต่อขึ้นเอง
