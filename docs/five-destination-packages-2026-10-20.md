# แพ็กเกจแยก 5 จุดหมาย — 20 ตุลาคม 2026

ตามคำขอปรับล่าสุด หน้าราคาใช้การ์ดเรียงข้างกันและขึ้นแถวใหม่: 3 คอลัมน์บนคอมพิวเตอร์ 2 คอลัมน์บนแท็บเล็ต และ 1 คอลัมน์บนมือถือ เรียงนครหลวงเวียงจันทน์ วังเวียง หลวงพระบาง หนองเขียว และเมืองงอย ตามด้วยแพ็กเกจจำปาสักเดิม การ์ดแสดงเฉพาะภาพ ชื่อจุดหมาย จำนวนวัน ราคาตัวอย่างต่อท่าน และปุ่มเปิดหน้ารายละเอียด ส่วนชื่อโปรแกรม ไฮไลต์ และกิจกรรมรายวันอ่านได้เมื่อกดเข้าไป

| จุดหมาย | ระยะเวลาตัวอย่าง | ราคาตัวอย่างต่อท่าน |
| --- | --- | ---: |
| นครหลวงเวียงจันทน์ | 2 วัน 1 คืน | 2,900 บาท |
| วังเวียง | 3 วัน 2 คืน | 4,900 บาท |
| หลวงพระบาง | 3 วัน 2 คืน | 5,900 บาท |
| หนองเขียว | 3 วัน 2 คืน | 6,500 บาท |
| เมืองงอย | 3 วัน 2 คืน | 6,900 บาท |

ใช้ราคาตัวอย่างตามที่เจ้าของอนุญาต ยังไม่มีการระบุว่ารวมรถ โรงแรม อาหาร หรือค่าเข้าชม จนกว่าจะได้รับข้อมูลที่ยืนยันจากบริษัท แพ็กเกจจำปาสักเดิมยังอยู่ ราคาแสดง 8,900 บาทต่อท่าน ระยะเวลา 4 วัน 3 คืน

หน้ารายละเอียดใช้ชื่อจุดหมายเป็นหัวข้อหลัก เปิดโปรแกรมทุกวันให้อ่านได้ทันที มีรายการกิจกรรม สถานที่ ลิงก์แผนที่ ไฮไลต์ ความเหมาะสมของกิจกรรม และหัวข้อราคา/รายละเอียดที่ต้องตกลงก่อนจัดทริป การสอบถามรักษารหัสแพ็กเกจที่ลูกค้าเลือกไว้ ภาพจริงแสดงเครดิตตามแหล่งที่มา หนองเขียวและเมืองงอยมีหน้าราคา โปรแกรม และภาพของตัวเอง แม้อยู่ในแขวงหลวงพระบางเหมือนกัน

ขนาดตัวอักษรหลักในการ์ดแพ็กเกจ 16 พิกเซล ชื่อจุดหมาย 25 พิกเซล ราคา 36 พิกเซล และกิจกรรมรายวัน 16–17 พิกเซล ในหน้ารายละเอียดยังเข้าถึงราคาก่อนรายการโปรแกรมได้

## ผลตรวจ

- สร้างหน้าเว็บสำเร็จ 252 หน้า โดยรวมหน้าแพ็กเกจใหม่ทั้งไทยและอังกฤษ
- ทดสอบข้อมูล เส้นทาง รูปภาพ และหน้า HTML ที่เปิดได้โดยไม่ใช้ JavaScript ผ่าน 39/39
- ทดสอบเบราว์เซอร์ผ่าน 20/20 รวมการเปิดโปรแกรมทั้ง 5 จุดหมาย การสอบถาม กรอง/เรียงราคา และภาพของสถานที่เดิมครบ 86 แห่ง
- ตรวจไวยากรณ์ JavaScript และตัวสร้างหน้าเว็บผ่าน
- ตรวจหน้ารวมแบบการ์ดล่าสุด 4 รูปแบบ ที่ความกว้าง 320, 390, 768 และ 1440 พิกเซล ทั้งไทยและอังกฤษ ไม่พบเนื้อหาล้นแนวนอนหรือข้อผิดพลาด JavaScript หน้ารายละเอียดคงรูปแบบที่ตรวจไว้ก่อนหน้า
- ตัวตรวจ layout ไม่พบรายการแจ้งเตือน
