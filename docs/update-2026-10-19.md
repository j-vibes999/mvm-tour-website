## สิ่งที่ปรับแล้ว

- แก้ All ในแพ็กเกจให้ล้างภาคที่เคยเลือก พร้อมเก็บตัวกรองใน URL เพิ่มเลือกจำนวนวัน และคงการเรียงราคา
- แก้เมนูแนวนอนให้เลื่อนภายในพื้นที่เหนือแถบล่าง
- ป้ายแผนที่รองรับวางเมาส์อ่านต่อ กดลิงก์เข้าหน้าแขวง และ Escape ปิดโดยคง focus
- เพิ่มค้นหาไทย/อังกฤษ รองรับชื่อเมือง เช่น วังเวียง/Vang Vieng และเลือกประเภทสถานที่ พร้อมสถานะไม่พบผลและล้างตัวกรอง
- เพิ่มหัวใจเก็บสถานที่ในเบราว์เซอร์ หน้ารวมรายการ และส่งรายการเข้าสู่การเตรียมทริป ไม่มีการสมัครสมาชิก
- เพิ่มหน้าสอบถามที่คงชื่อแพ็กเกจ/แขวง/สถานที่/รายการที่เลือก รับวัน จำนวนคน และหมายเหตุ แล้วแสดงข้อความให้ตรวจ คัดลอก หรือดาวน์โหลด ไม่ส่งข้อมูลเองและไม่เก็บข้อมูลส่วนตัวบนเซิร์ฟเวอร์
- ช่องทางที่ยังว่างถูกซ่อน แสดงสถานะที่เข้าใจได้แทนปุ่มเสีย โค้ดพร้อมเปิด LINE/WhatsApp/อีเมลเมื่อใส่ค่าจริง
- ขยายโปรแกรมตัวอย่างทั้งสามเป็นรายวัน มีสถานที่จริงที่กดดูต่อได้ ลิงก์แผนที่รายวัน ลักษณะกิจกรรม และรายการที่ต้องยืนยันก่อนจอง ยังคงระบุราคา/โปรแกรมเป็นตัวอย่าง
- เพิ่ม FAQ และหน้าเกี่ยวกับเราแบบมีโครงสร้าง เตรียมช่องแสดงทีม รถ พื้นที่บริการ รีวิว และข้อมูลบริษัท เมื่อเจ้าของใส่ข้อมูลจริง
- ภาพหลักแบบภาพถ่ายครบ 18 แขวง เพิ่มแหล่งภาพใหม่ 18 ภาพ รวม 46 ภาพถ่ายมีเครดิต; มีภาพตรงสถานที่ 44/86 แห่ง
- เก็บรูปถ่ายเป็น WebP ในเว็บ 135 ไฟล์ มีขนาดย่อยและ lazy loading พร้อมหน้าทดแทนเมื่อภาพโหลดไม่ได้ คลังรูปถ่ายรวม 16.5 MiB ไม่ใช่ขนาดโหลดหน้าแรก
- URL จริงแยก `/th/` และ `/en/` พร้อมเนื้อหา HTML เฉพาะหน้า title/description/canonical/OG/hreflang, sitemap และ robots ลิงก์เก่ายังคงเปิดได้ หน้า saved/inquiry/404 ถูกกำหนด noindex
- เพิ่ม build สร้าง 246 หน้าใน `build/` และเปลี่ยน hosting manifest ให้ชี้ build โดยคง project_id เดิม

## ผลตรวจ

- `npm test`: 35 รายการผ่าน
- `npm run test:browser`: 14 รายการผ่าน ครอบคลุมบั๊กเดิม ค้นหา รายการที่บันทึก แบบฟอร์ม ดาวน์โหลด การเปลี่ยนภาษา การคืน focus Browser Back/Forward ลิงก์เก่า รูปโหลดไม่ได้ และข้อมูลบริษัทเมื่อใส่จริง
- `npm run check`: ผ่าน
- axe-core ตรวจ 6 หน้าตัวแทนตาม WCAG 2 A/AA และ 2.1 AA ไม่พบ violation ที่เครื่องมือตรวจได้ ไม่ใช่การรับรองการเข้าถึงครบถ้วน
- ตรวจภาพ Chromium บนคอมพิวเตอร์และมือถือ รวมหน้ากว้าง 320/390/768/1440 และแนวนอน 844×390 ไม่พบ runtime error/หน้าล้นในชุดที่ตรวจ
- ยังไม่ได้ทดสอบบนโทรศัพท์จริง Safari/VoiceOver หรือวัด Core Web Vitals บนโฮสต์จริง

## ข้อมูลที่ยังต้องได้จากเจ้าของ

- LINE/WhatsApp/โทรศัพท์/อีเมล/ที่อยู่ และลิงก์ Facebook จริง ขณะนี้ยังติดต่อบริษัทผ่านเว็บไซต์ไม่ได้ จึงให้เตรียมและดาวน์โหลดข้อความได้ก่อน
- ราคา เงื่อนไข จุดรับ–ส่ง ที่พัก บริการที่รวม/ไม่รวม และรายละเอียดการยืนยันทริปจริง
- ข้อมูลบริษัท ทีม รถ ภาพให้บริการ และรีวิวที่ได้รับอนุญาต ไม่มีการแต่งสิ่งเหล่านี้ขึ้นมา
- ภาพที่ตรวจสอบได้อีก 42 สถานที่ รายชื่ออยู่ในคู่มือ media การแสดงผลยังใช้ภาพทดแทนที่ออกแบบไว้จนกว่าจะมีภาพตรงสถานที่
