# บันทึกตรวจภาษาเว็บไซต์ MVM Group — 20 ตุลาคม 2026

เว็บไซต์ใช้ภาษาไทย (`th`), ภาษาลาว (`lo`), ภาษาอังกฤษ (`en`) และภาษาจีนตัวย่อ (`zh`) การแปลลาวและจีนจัดทำเป็นข้อความแยกตามเนื้อหาจริง ไม่ใช้การแปลอัตโนมัติระหว่างเปิดหน้าเว็บ

## ขอบเขตการตรวจ

- แปลและทวนความหมายของคลังสถานที่ครบ 259 ข้อความ รวม 518 คำแปล ตรวจชื่อสถานที่ รายละเอียด ระยะทาง จำนวนวัน เวลา และปีที่ปรากฏในต้นฉบับ
- ใช้ชื่อแขวงภาษาลาวเดิมใน `content.js` เป็นรูปแบบมาตรฐาน และเทียบชื่อเฉพาะที่จำเป็นกับแหล่งข้อมูลทางการ
- ตรวจให้คีย์ตรงกับต้นฉบับทุกตัว ไม่มีช่องว่างหรือข้อความตัวอย่างแทนคำแปล และไม่มีอักษรไทยปะปนในคำแปลลาวหรือจีน
- ตัวเลขบางรายการเปลี่ยนรูปแบบตามภาษาโดยคงความหมาย เช่น “two days” เป็น “2 ມື້” และ “四千美岛” เป็นชื่อจีนของสี่พันดอน
- ทวนคำศัพท์ร่วมกับคลังโปรแกรมทัวร์เพื่อให้ชื่อเมืองและสถานที่ใช้รูปแบบเดียวกันทั้งเว็บไซต์

การตรวจภาษาในรอบนี้ดำเนินการโดย AI โดยอ้างอิงแหล่งข้อมูลด้านล่าง และมีการตรวจทานข้ามชุดคำแปลระหว่างตัวแทน AI ไม่ได้ผ่านผู้พิสูจน์อักษรเจ้าของภาษาที่เป็นมนุษย์ และไม่ได้รับรองว่าการทับศัพท์สถานที่ขนาดเล็กทุกแห่งมีชื่อจีนทางการ หากไม่มีรูปแบบมาตรฐานที่ยืนยันได้ จะคงชื่ออักษรละตินในวงเล็บเพื่อระบุตัวสถานที่อย่างชัดเจน

## ผลตรวจยืนยัน — 21 ตุลาคม 2026

คลังคำแปลครบ: สถานที่ 259 รายการ รายละเอียด 198 รายการ โปรแกรม/บริษัท/หน้าแรก 241 รายการ และ UI 314 รายการ (มีข้อความที่ใช้ร่วมกันระหว่างคลัง) แต่ละรายการมีคำแปลลาวและจีน ไม่มีอักษรไทยปะปนในคำแปล ส่วนสัญลักษณ์ ฿ ยังคงใช้เพื่อสื่อราคาเป็นบาทไทย

การตรวจทานอิสระเพิ่มเติมแก้การแยก Don Khon กับ Don Khong ให้ตรงตัวสถานที่ ใช้ชื่อจีนของถ้ำกางให้ตรงกันทุกหน้า แก้ข้อความรับจากตัวเมืองให้ไม่สื่อว่ารวมรับ–ส่ง และใช้หัวข้อภาษาจีนแบบสมบูรณ์ เช่น “第 1 天” แทน “第 1”

- `npm run check` ผ่าน รวมโมดูลภาษาและคลังคำแปลทั้ง 4 ไฟล์
- `npm test` ผ่าน 43/43 รวมความครบถ้วนของทุกฟิลด์และกิจกรรมรายวัน การค้นหาชื่อลาว/จีน และข้อความสอบถามทั้งสองภาษา
- Browser tests ผ่าน 36/36 รวมการสลับทุกภาษาโดยคงแพ็กเกจเดิม และการสลับบนจอ 320/390 พิกเซลโดยคงข้อมูลแบบฟอร์มครบ
- ตรวจหน้า Lao/Chinese ที่มีและไม่มี JavaScript พร้อม canonical และ hreflang ครบ 4 ภาษา
- สร้างไฟล์เว็บได้ 502 หน้า แยก `/th/`, `/lo/`, `/en/`, `/zh/` ใช้ `zh-Hans` ใน metadata
- ตรวจภาพ 11 กรณีที่ขนาด 320, 390, 768 และ 1440 พิกเซล และปรับส่วนหัวให้ปุ่มเลือกภาษาไม่ล้นจอ 320 พิกเซล ไม่พบข้อผิดพลาด JavaScript ในกรณีที่ตรวจยืนยัน
- ฟอนต์ Noto Sans Lao เก็บในโครงการพร้อม SIL Open Font License; ภาษาจีนใช้ฟอนต์จีนของอุปกรณ์ การตรวจมือถือเป็นการจำลองใน Chromium
