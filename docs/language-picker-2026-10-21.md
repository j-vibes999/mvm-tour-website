# เมนูภาษาแบบ dropdown — 21 ตุลาคม 2026

ส่วนหัวใช้ปุ่มภาษาเดียวบนคอมพิวเตอร์ แท็บเล็ต และมือถือ กดเพื่อเปิดไทย ลาว อังกฤษ และจีน พร้อมเครื่องหมายภาษาที่กำลังใช้อยู่ โทนสีเขียว ครีม และทองสอดคล้องกับเว็บไซต์เดิม

## การเลือกภาษาเมื่อเปิดเว็บ

1. URL ที่ระบุภาษา เช่น `/lo/` หรือ `/zh/package/luang-prabang-discovery/` เปิดตามภาษานั้น เพื่อให้ลิงก์ที่ส่งต่อมีภาษาคงเดิม
2. หากเข้า URL หลัก `/` ใช้ภาษาที่ผู้ใช้เคยเลือกเองจาก `localStorage` ชื่อ `mvm-language`
3. หากยังไม่มีตัวเลือกที่บันทึกไว้ อ่าน `navigator.languages` หรือ `navigator.language` ของเบราว์เซอร์ แล้วเลือกภาษาที่รองรับตามลำดับความต้องการ
4. หากไม่พบภาษาที่รองรับ ใช้ภาษาอังกฤษ

รองรับรหัสย่อย เช่น `th-TH`, `lo-LA`, `en-GB`, `zh-CN` และ `zh-TW` โดยภาษาจีนแสดงเป็นจีนตัวย่อตามเนื้อหาที่มีอยู่ การตรวจอัตโนมัติไม่บันทึกเป็นตัวเลือกส่วนตัว การกดเลือกเองเท่านั้นจะบันทึก รวมถึงการเลือกภาษาปัจจุบันซ้ำ หากเบราว์เซอร์ไม่อนุญาตให้เก็บข้อมูล ระบบยังเปลี่ยนภาษาในหน้าปัจจุบันได้

## การใช้งาน

- กดปุ่มภาษาเพื่อเปิด/ปิด กดด้านนอกหรือย้ายโฟกัสออกเพื่อปิด
- ใช้ลูกศรขึ้น/ลง, Home และ End เลือกรายการ ใช้ Enter หรือ Space ยืนยัน และ Escape ปิดพร้อมคืนโฟกัส
- การเปลี่ยนภาษารักษาหน้าปัจจุบัน แพ็กเกจที่เลือก และข้อมูลร่างในแบบฟอร์มสอบถาม
- หากปิด JavaScript หน้าแต่ละภาษายังมี dropdown แบบ `<details>` พร้อมลิงก์สลับภาษา แต่ไม่ตรวจภาษาของเบราว์เซอร์อัตโนมัติ
- ปุ่มและรายการมีพื้นที่แตะอย่างน้อย 44 และ 48 พิกเซลตามลำดับ รองรับการลดการเคลื่อนไหว

## ผลตรวจ

- `npm run check` ผ่าน
- `npm test` ผ่าน 45/45 รวมลำดับการเลือกภาษาและรหัสภาษาย่อย
- `npm run test:browser` ผ่าน 38/38 รวมการตรวจภาษาอัตโนมัติ การจำตัวเลือก การเปิดลิงก์ภาษาที่ระบุ การรักษาข้อมูลสอบถาม และการใช้คีย์บอร์ด
- Build สร้าง 502 หน้า โดยคง URL และ metadata ทั้ง 4 ภาษา
- ตรวจภาพ 5 กรณี: คอมพิวเตอร์ภาษาไทย 1440 พิกเซล มือถือภาษาจีน 320 พิกเซล มือถือภาษาลาว 390 พิกเซล แท็บเล็ตภาษาอังกฤษ 768 พิกเซล และภาษาลาวแบบปิด JavaScript 320 พิกเซล ทั้งปุ่มและ dropdown อยู่ในขอบจอ ไม่พบข้อผิดพลาด JavaScript ในกรณีที่ตรวจ

ภาพและข้อมูลขนาดอยู่ใน `.artifacts/language-picker-2026-10-21/round1/` การตรวจบนมือถือเป็นการจำลองใน Chromium
