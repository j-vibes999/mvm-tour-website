# ตรวจและปรับ Interaction ของ MVM Group — 20 ตุลาคม 2026

เป้าหมายคือให้เว็บไซต์มีชีวิตชีวา ตอบสนองชัดเจน และอ่านสบาย โดยคงโทนป่าเขียว–ครีม ภาพสถานที่ เนื้อหา ราคา และรูปแบบการ์ดแพ็กเกจที่เจ้าของเลือกไว้

## ขอบเขตที่ตรวจ

ตรวจหน้าแรก สำรวจ/ค้นหา แผนที่ ภาค/แขวง แถบสถานที่ หน้าดูภาพสถานที่เต็มจอ รายการแพ็กเกจ รายละเอียดโปรแกรม รายการที่บันทึก แบบฟอร์มเตรียมข้อความสอบถาม เกี่ยวกับบริษัท FAQ เครดิตภาพ เมนู ส่วนท้าย การเปลี่ยนภาษา และแถบเครื่องมือมือถือ รวมเส้นทางตรง/ปุ่มย้อนกลับ รูปโหลดไม่สำเร็จ และการใช้คีย์บอร์ด

เอฟเฟกต์ใช้ CSS และ Web Animations API โดยไม่มีไลบรารีเพิ่ม การเปลี่ยนหน้ามีเพียงการปรากฏของหัวข้ออย่างสั้น เนื้อหาอื่นแสดงตามปกติ ไม่มีการซ่อนแต่ละส่วนเพื่อรอเลื่อนมาถึง การเปลี่ยนตัวกรองตอบสนองทันทีและไม่เคลื่อนหน้าระหว่างพิมพ์ค้นหา

## ปัญหาการใช้งานที่แก้

- เมนูมือถือค้างเมื่อเลือกหน้าที่เปิดอยู่ ปรับให้สถานะ ปุ่ม และการปิดตรงกัน พร้อมคืนโฟกัสและปิดเมื่อออกจากเมนูด้วยคีย์บอร์ด
- เหตุการณ์เลื่อนในหน้าดูสถานที่ที่ยังค้างอยู่สามารถเขียนทับ URL ของหน้าสอบถาม แก้การยกเลิกงานที่ค้างและตรวจหน้าที่เปิดก่อนเปลี่ยนลิงก์
- ค้นหาแล้วโฟกัสยังอยู่เหนือผลลัพธ์ แก้ให้หัวข้อผลลัพธ์ได้รับโฟกัสและอยู่ใต้เมนูคงที่
- เปลี่ยนสถานที่ด้วยคีย์บอร์ดแล้วโฟกัสตกไปที่ body แก้ให้หัวข้อสถานที่ถัดไปรับโฟกัสเมื่อจำเป็น
- เพิ่มพื้นที่ด้านล่างตาม safe-area ของอุปกรณ์ เพื่อรองรับแถบเครื่องมือมือถือ
- ป้องกันการเปิด–ปิดรายละเอียดผิดสถานะเมื่อแตะเร็ว ใช้ native activation หรือเปลี่ยนการตั้งค่าลดการเคลื่อนไหวระหว่างเอฟเฟกต์
- ปุ่มเล่นบนจอสัมผัสเคยเปลี่ยนโหนดย่อยระหว่าง pointerdown จน click ไม่เกิด แก้ให้คงโหนดปุ่มและอัปเดตเฉพาะสถานะที่เปลี่ยน

## การเข้าถึงและการเคลื่อนไหว

รองรับ `prefers-reduced-motion` และการเปลี่ยนค่าขณะเปิดหน้าเว็บ ลดการเคลื่อนภาพ ปิดการเล่นสไลด์ และยุติเอฟเฟกต์ที่กำลังทำงานโดยคงสถานะสุดท้ายไว้ การกระทำจากคีย์บอร์ดทำงานทันที มีเส้นโฟกัสที่มองเห็นได้ ปุ่มที่ยังอยู่ระหว่างปิดไม่รับโฟกัส และข้อความแจ้งสถานะยังอ่านได้
