# ภาพสถานที่และเครดิต MVM Group

อัปเดต 20 ตุลาคม 2026 มีภาพครบ **86/86 สถานที่** ใน 18 แขวง: **ภาพถ่ายจริง 63 แห่ง** และ **ภาพประกอบ AI 23 แห่ง** เติมจากเดิมที่ขาด 42 แห่ง ด้วยภาพจริง 19 แห่งและภาพประกอบ AI 23 แห่ง

ค้นหาภาพจริงก่อน ภาพที่สร้างอ้างอิงข้อมูลและภาพของสถานที่จริง เพื่อคุมภูมิประเทศ รูปทรงอาคาร และบรรยากาศให้สมจริง มีป้าย “ภาพประกอบ AI” / “AI illustration” บนการ์ดและหน้าชมภาพ พร้อมลิงก์อ้างอิง แยกจากภาพถ่ายหน้างาน

## รายการภาพ

- [รายการครบ 86 สถานที่](place-image-coverage.json) ระบุไฟล์ ประเภทภาพ ผู้ถ่าย/ผู้สร้าง ใบอนุญาต และแหล่งที่มา
- [ทะเบียนแหล่งที่มาภาพทั้งหมด](image-source-register.md) รวม 88 ภาพในคลัง รวมภาพตัวแทนแขวง
- หน้าเครดิต `/th/credits/` และ `/en/credits/` เปิดตรงรายการของภาพที่เลือกจากหน้าชมภาพได้

## ไฟล์และการดูแล

`dist/complete-media.js` เป็นคลังรวมที่หน้าเว็บและตัวสร้าง HTML ใช้ร่วมกัน รวมข้อมูลจาก `content.js`, `media-catalog.js` และชุดเติมภาพ `media-north.js`, `media-central.js`, `media-south.js`, `media-north-completion-a.js`, `media-north-central-completion.js`, `media-south-completion.js`, `media-root-completion.js`

| export | หน้าที่ |
| --- | --- |
| `extraPhotos` | ประเภทภาพ ผู้ถ่าย/ผู้สร้าง ใบอนุญาต และแหล่งที่มา |
| `provincePhotos` | รหัสแขวง → ภาพตัวแทน |
| `placePhotos` | รหัส `แขวง/สถานที่` → รหัสภาพ |
| `localPhotos` | ไฟล์ WebP, `srcset`, ขนาดต้นฉบับ และขนาดย่อยจริง |

ไฟล์พร้อมแสดงอยู่ใน `dist/assets/images/photos/` และ `dist/assets/images/places-*/` ต้นฉบับ PNG ของภาพสร้างและภาพอ้างอิงสำหรับทำงานอยู่ใน `.artifacts/` ซึ่งไม่รวมในเว็บ `build/`

## ขนาดและการโหลด

คลังภาพสถานที่และแขวงมี WebP **249 ไฟล์ รวม 32.7 MiB** ไฟล์ใหญ่ที่สุด 551 KiB เป็นขนาดคลังทั้งหมด ไม่ใช่ข้อมูลที่ต้องโหลดเมื่อเปิดหน้าแรก

รูปมีหลายขนาด เช่น 480, 960 และสูงสุด 1600 พิกเซล ภาพสร้างใช้สูงสุด 1536 พิกเซล ไม่ขยายเกินต้นฉบับ เบราว์เซอร์เลือกขนาดตามพื้นที่แสดง รูปนอกจอใช้ lazy loading ภาพแนวตั้งในหน้าชมภาพแสดงเต็มภาพเพื่อไม่ตัดส่วนสำคัญ

## เครดิตและการเปลี่ยนภาพ

ภาพถ่ายแต่ละภาพใช้ใบอนุญาตของต้นฉบับ เช่น CC BY, CC BY-SA หรือ Public domain ให้คงชื่อผู้ถ่าย ลิงก์ต้นฉบับ ลิงก์ใบอนุญาต และคำแจ้งการย่อ/แปลง WebP ไว้ พื้นที่แสดงบางแบบอาจครอปภาพ

ภาพ AI ใช้ `kind: 'generated'` และ `license: 'AI-generated illustration'` ไม่รับใบอนุญาตของภาพอ้างอิงมาอ้างเป็นของภาพสร้าง เมื่อเปลี่ยนเป็นภาพถ่ายจริง ให้ปรับ metadata และเครดิต เว็บจะเลือกป้ายตามประเภทภาพอัตโนมัติ

คำสั่งสร้างเต็มและข้อมูลอ้างอิง:

- [ภาคเหนือชุดแรก](image-prompts-north.json)
- [ภาคกลางชุดแรก](image-prompts-central.json)
- [ภาคใต้ชุดแรก](image-prompts-south.json)
- [ภาคเหนือชุดเติม](image-prompts-north-a.json)
- [ภาคเหนือและกลางชุดเติม](image-prompts-north-central.json)
- [ภาคใต้ชุดเติม](image-prompts-south-completion.json)
- [สาละวัน เฮือนหิน และพระธาตุไซเชษฐา](image-prompts-root.json)

`node scripts/cache-photos.mjs` สร้าง cache ของภาพเดิม 46 ภาพเท่านั้น และอัปเดต `media-catalog.js` ไม่ได้สร้างชุดเติมหรือเรียก ImageGen ใหม่

หลังเปลี่ยนภาพหรือ mapping ให้รัน `npm test`, `npm run check` และ `npm run test:browser` ชุดตรวจเปิดรูปครบ 86 สถานที่ ตรวจไฟล์ในเว็บ ป้าย AI และลิงก์เครดิตไทย/อังกฤษ พร้อม build เว็บใหม่
