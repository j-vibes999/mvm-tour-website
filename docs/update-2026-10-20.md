# เติมภาพสถานที่ครบ — 20 ตุลาคม 2026

เว็บไซต์มีภาพครบ 86 สถานที่ใน 18 แขวง: 63 แห่งใช้ภาพถ่ายจริง และ 23 แห่งใช้ภาพประกอบ AI ที่อ้างอิงข้อมูลและภาพของสถานที่จริง รอบนี้เติม 42 แห่งที่ขาดภาพ แบ่งเป็นภาพจริง 19 แห่งและภาพประกอบ AI 23 แห่ง

ภาพประกอบมีป้าย “ภาพประกอบ AI” / “AI illustration” และลิงก์อ้างอิง แยกจากเครดิตผู้ถ่ายของภาพจริง หน้าเครดิตเปิดตรงไปยังข้อมูลภาพที่เลือกได้ มีข้อความกำกับประเภทภาพใน alt และข้อมูลรูปแชร์ด้วย

เก็บภาพพร้อมใช้งานเป็น WebP หลายขนาดในเว็บ ไม่พึ่งโหลดรูปจากเว็บไซต์ต้นทางขณะใช้งาน ต้นฉบับภาพสร้างและภาพอ้างอิงสำหรับทำงานอยู่ใน `.artifacts/` และไม่รวมใน `build/` ภาพแนวตั้งในหน้าชมภาพแสดงเต็มภาพเพื่อไม่ตัดส่วนสำคัญ

ผลตรวจ:

- `npm test`: ผ่าน 37 รายการ รวมตรวจภาพครบ 86 สถานที่และแหล่งอ้างอิงภาพ AI
- `npm run check`: ผ่าน พร้อมตรวจ syntax ของคลังภาพรวมและสคริปต์สร้าง HTML เพิ่มเติม
- `npm run test:browser`: ผ่าน 17 รายการ รวมเปิดรูปหลักและรูปย่อครบทั้ง 86 สถานที่บนมือถือ ป้าย AI ไม่ซ้อนกับประเภทสถานที่ ลิงก์แหล่งที่มาทั้งไทย/อังกฤษ และแถบรูปย่อคงขนาดเดิมเมื่อโหลดรูปไม่ได้
- สร้าง HTML 246 หน้าเรียบร้อย พร้อมข้อมูลภาพของสถานที่ในแต่ละหน้า
- ตรวจ contact sheet ของภาพที่เพิ่ม และตรวจการแสดงผลจริงทั้งเดสก์ท็อปและมือถือ
