## สิ่งที่ยืนยันว่าทำดีขึ้นจริง

1. **หน้าแรกมีหน้าจอเริ่มต้นที่ออกแบบแล้วก่อนแอปพร้อม**: เมื่อหน่วง app.js พบภาพหลักและหัวเรื่องหนึ่งชุด ขณะที่ `__mvmReady=false` และซ่อนข้อความ fallback อยู่ ไม่เห็นรายการ bullet แทนดีไซน์ในกรณีโหลดปกติ
2. **ส่วนหัว notebook ไทยและอังกฤษแก้แล้ว**: มีเมนูเต็มและปุ่มวางแผนในช่วงที่รายงานระบุ บางความกว้างลดปุ่มเป็นไอคอนแต่ยังมีชื่อสำหรับการเข้าถึง
3. **เริ่มต้นด้วย pointer mode แล้ว**: hover ไม่ต้องรอคลิกแรก ส่วน keyboard mode ยังเปลี่ยนเมื่อมีการกดคีย์
4. **About มีแกลเลอรี 3 ภาพ และหัวข้อที่เคยซ้ำเปลี่ยนแล้ว**: รูปเหล่านี้เป็นภาพสถานที่/วิถีชีวิต ไม่ใช่หลักฐานทีมบริษัท
5. **CSS มีการลบของเก่าบางส่วนจริง**: styles.css ลดจาก 57,204 เป็น 48,078 ไบต์; ไม่พบ selector/ฟังก์ชันเก่าหลายชื่อ เช่น dest-card, lang-switch, destCard, customCard และ valueList แล้ว พร้อมรวม stylesheet เป็น site.css ใน build อย่างไรก็ตาม ยังมีความขัดกันของ transition ที่ต้องเก็บ
6. **ไทย/อังกฤษไม่ต้องโหลดคลังลาว/จีนในการเปิดปกติ**: เป็นการลดงานเริ่มต้นที่มีประโยชน์ แม้มีผลข้างเคียงต่อการค้นหาและการเลือกภาษาดังข้อค้นพบ
7. **มีไอคอนมือถือจริง**: apple-touch-icon.png มีขนาด 180×180 และมี manifest
8. **เอฟเฟกต์หลักทำงานหลายส่วน**: กดภาพถี่แล้วไปภาพล่าสุดได้ ระบบบันทึกสถานที่ยังอยู่และอนุภาคถูกล้างหลังจบ; reduced motion ยกเลิกการซูมและการเคลื่อนของการ์ดได้; forward transition จากวัดเชียงทองไป viewer ใช้รูปเดียวกันและจบได้; Escape ปิด viewer ได้
9. **เนื้อหายังพร้อมแม้ไม่มี animation**: ไม่พบการทำให้ทั้งหน้าเป็นพื้นที่ว่างเพื่อรอ scroll reveal ในกรณีที่ตรวจ
10. **เงื่อนไขความจริงของธุรกิจยังอยู่**: ราคายังระบุตัวอย่าง ไม่มีรีวิว บุคลากร หรือข้อมูลบริษัทที่แต่งขึ้นเพื่อเติมช่องว่าง

### F01 · P1 · ไฟล์ “เปิดเว็บ.command” เปิดผิดโฟลเดอร์สำหรับระบบ URL ปัจจุบัน

- **หลักฐาน:** `เปิดเว็บ.command:6` เปลี่ยนเข้า dist แล้วเปิด Python server แต่ระบบมี public URL เช่น `/en/` และ `/th/package/.../` ซึ่งสร้างเป็นไฟล์จริงใน build เท่านั้น
- **ทำซ้ำ:** เปิดเซิร์ฟเวอร์ที่ dist แล้วเรียก `/en/` ได้ HTTP 404 ตรงกับพฤติกรรมของ launcher ปัจจุบัน
- **ผลกระทบ:** หน้าแรกอาจเปิดแอปได้ แต่ลิงก์ตรงและการรีโหลดหน้าเฉพาะมีโอกาส 404 และผู้ใช้ไม่ได้เห็น first-paint/static SEO/build optimization ที่เพิ่งเพิ่ม จึงประเมินงานล่าสุดผิดรุ่นได้
- **อีกสถานะที่พบ:** build จริงในโฟลเดอร์ผู้ใช้ยังไม่ตรงกับ source ล่าสุด และไม่มี ui-kit.js, motion.css, features.css รุ่นใหม่
- **แนะนำ:** ใช้ขั้นตอนเปิดเว็บเดียวกันให้ build ก่อน แล้ว serve build; แจ้งกรณียังไม่ติดตั้ง dependencies และอย่าเปิด server เก่าคนละ directory ต่อโดยเงียบ ๆ
- **ประเภท:** ปัญหาวิธีเปิด/ส่งมอบที่ค้างมาจากเดิม ไม่ใช่ข้อผิดของเอฟเฟกต์ใหม่

## ลำดับงานที่แนะนำ

1. **ปิดงานพื้นฐานก่อน:** ทำวิธีเปิดเว็บและ build ให้เป็นชุดเดียว แก้ป้ายแผนที่บังการกด race ของภาษา การค้นหาข้ามภาษา fallback ตอนเริ่มแอปไม่ได้ และประเด็นการเข้าถึงที่ยืนยันแล้ว พร้อม regression tests เฉพาะพฤติกรรมเหล่านี้
2. **ขอข้อมูลจริงที่ทำให้ลูกค้าติดต่อได้:** อย่างน้อยช่องทางที่บริษัทดูแลจริงหนึ่งช่อง พร้อมชื่อผู้รับผิดชอบข้อมูลบริษัท การมีรีวิวหรือรูปทีมครบไม่ควรขวางการใส่ช่องทางติดต่อนี้
3. **เก็บระยะ 1 ให้สอดคล้องกัน:** Pause หยุดทุกการเคลื่อนใน hero, card lift นุ่มจริง, transition จับคู่ภาพที่ถูกต้อง แล้วตัดสินใจว่า Back จำเป็นต้อง animate หรือไม่ รูปซ้ำลดได้อีกแต่ไม่ต้องห้ามรูปซ้ำทุกแห่งหากช่วยให้จำจุดหมายได้
4. **ทำ viewer มือถือกับแผนที่ให้ดี:** ทั้งสองส่วนช่วยตัดสินใจเลือกเที่ยวโดยตรง คงปุ่มปิดและรายละเอียดแบบกระชับที่ผู้ใช้เลือกไว้ ปรับรูปใหญ่/การเลื่อนก่อนเพิ่ม gesture ซับซ้อน
5. **เพิ่มภาพในโปรแกรมและการย้ายรายการที่อยากไป:** ใช้ภาพรายวันขนาดพอดี มีปุ่มขึ้น/ลงที่ใช้คีย์บอร์ดได้ แล้วค่อยเสริมลากเรียงเป็นทางเลือก คงการ์ดแพ็กเกจแบบกระชับตามความต้องการเดิม
6. **ทำ month chooser หลังข้อมูลพร้อม:** ใช้ months ที่ตรวจแล้ว ระบุว่าสภาพอากาศเป็นข้อมูลประกอบ ไม่บอกว่าเดือนที่ไม่มีข้อมูลเที่ยวไม่ได้
7. **พิจารณา day story และ wizard เป็นงานเสริม:** ภาพเรื่องราวช่วยสร้างอารมณ์ได้ แต่แบบฟอร์มเพียงสี่ช่องอาจไม่จำเป็นต้องแบ่งสามขั้น ควรเทียบว่าช่วยลูกค้าจริงหรือเพิ่มจำนวนคลิก
8. **เกลาภาษาต่อจากรายงาน copy เดิม:** เลือกเสียงที่อบอุ่นและเห็นภาพ ตรวจข้อความทั้งหน้าของแต่ละภาษา และทวนชื่อ/ข้อมูลจริง ปรับอังกฤษและคีย์ลาว/จีนควบคู่กัน รายงานนี้ไม่ได้ยืนยันว่าข้อความเชิงโฆษณาทั้งคลังถูกเขียนใหม่แล้ว

รักษาของที่ตอบโจทย์ผู้ใช้ไว้: ภาพสวยนำหน้า ราคาไปดูในเมนู/หน้าโปรแกรม การ์ดแพ็กเกจสั้น รายละเอียดค่อยเปิด ปุ่มเล่น/หยุดเป็นสัญลักษณ์ และ 4 ภาษา พร้อมเคารพ reduced motion ไม่เพิ่มคำอธิบายเอฟเฟกต์เข้ามาทับภาพ
