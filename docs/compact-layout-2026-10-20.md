# หน้าทริปและสถานที่แบบกระชับ — 20 ตุลาคม 2026

ปรับตามคำขอให้ราคา แพ็กเกจ และรายละเอียดสถานที่ดูง่ายขึ้น คงโทนครีม–เขียว ภาพสถานที่ และข้อมูลเดิม

- หน้าแพ็กเกจ: หัวข้อสั้นลง การ์ดใช้ภาพเต็มความกว้างด้านบน ตามด้วยชื่อทริป จำนวนวัน และจุดเด่นแบบรายการ ราคาแยกเป็นแถบสีเขียวอ่อนพร้อมตัวเลขและหน่วยราคาในบรรทัดเดียว ปุ่มดูโปรแกรมเต็มความกว้างอยู่ใต้ราคา ใช้ลำดับเดียวกันบนคอมพิวเตอร์และมือถือ
- หน้าโปรแกรม: ย้ายราคาและปุ่มสอบถามมาอยู่ก่อนรายละเอียดทั้งหมด แสดงโปรแกรมรายวันแบบกดเปิด โดยเปิดวันแรกให้ก่อน รายละเอียดเส้นทาง ความเหมาะสม และเงื่อนไขยังอ่านได้ครบ
- หน้าชมสถานที่ทั้ง 86 แห่ง: เริ่มด้วยคำบรรยายสั้น ปุ่มวางแผนและบันทึก ส่วน 28 แห่งที่มีรายละเอียดเพิ่มเติม ใช้หัวข้อ “ข้อมูลเพิ่มเติม” แบบกดเปิดเพื่ออ่านข้อมูลเต็ม ไฮไลต์ เวลา การเดินทาง และข้อควรรู้
- ลดขนาดหัวข้อและความสูงการ์ดในหน้าแขวง ที่เที่ยวยอดนิยม ผลค้นหา และรายการที่บันทึก ปรับแถวภาพ/ข้อความและระยะห่างให้สม่ำเสมอ
- คงราคาตัวอย่าง ฿5,900 / ฿4,900 / ฿8,900 เครดิตภาพ และป้ายภาพ AI ไม่ได้ยืนยันราคาใหม่หรือเพิ่มข้อมูลบริการที่ยังไม่มี

ตัวอย่างผลบนจอ 390 × 844: หน้าโปรแกรมหลวงพระบางลดความสูงเริ่มต้นจาก 4,889 เป็น 2,935 พิกเซล (ประมาณ 40%) โดยเก็บเนื้อหาเต็มไว้ในหัวข้อที่เปิดอ่านได้ ราคาเริ่มที่ตำแหน่ง 440 พิกเซลและปุ่มสอบถามอยู่ในหน้าจอแรก

ไฟล์หลักคือ `dist/app.js` และ `dist/refinements.css` โดย `dist/index.html` โหลด refinements หลัง CSS เดิมเพื่อเก็บการปรับครั้งนี้แยกไว้ สร้างผลลัพธ์ใน `build/` ผ่าน `npm run build` ตามเดิม

ตรวจแบบรวมเดสก์ท็อป/มือถือและไทย/อังกฤษ 12 มุมมอง รวมจอแคบ 320 พิกเซล ไม่พบเนื้อหาล้นด้านข้างหรือ JavaScript error ภาพตรวจและข้อมูลขนาดอยู่ใน `.artifacts/compact-2026-10-20/round2/`

ปรับการ์ดราคาเพิ่มเติมตามข้อเสนอแนะ: เลิกใช้ภาพเป็นแถบแคบข้างข้อความบนมือถือ และแยกราคาจากปุ่มให้เทียบแพ็กเกจง่ายขึ้น ใช้กริด 3 คอลัมน์บนจอกว้าง, 2 คอลัมน์บนแท็บเล็ต และ 1 คอลัมน์บนโทรศัพท์ ภาพตรวจล่าสุดอยู่ใน `.artifacts/compact-2026-10-20/cards-round2/` สแกนโครงสร้าง layout ผ่านโดยไม่มีรายการแจ้งเตือน

การทดสอบที่เพิ่มตรวจการเปิดข้อมูลสถานที่ด้วยคีย์บอร์ด การส่งบริบทสถานที่เข้าแบบสอบถาม การเข้าถึงราคาก่อนโปรแกรมรายวัน และการเปิดวันถัดไปพร้อมลิงก์สถานที่ ชุดเดิมยังตรวจภาพหลัก/รูปย่อครบ 86 แห่ง ตัวกรอง การบันทึก ภาษา และประวัติการนำทาง

ผลตรวจสุดท้าย: `npm test` ผ่าน 37 รายการ, `npm run check` ผ่าน และ `npm run test:browser` ผ่าน 19 รายการ รวม 56 รายการ พร้อมสร้าง HTML 246 หน้าใหม่

เป็นการแก้ในเครื่องและสร้างชุดเว็บพร้อมใช้งาน ยังไม่ได้เผยแพร่ขึ้นเว็บไซต์ออนไลน์
