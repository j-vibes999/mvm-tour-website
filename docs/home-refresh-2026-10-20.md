# ปรับหน้าแรก MVM Group — 20 ตุลาคม 2026

ดำเนินการตามข้อเสนอที่เจ้าของอนุมัติ โดยคงโทนเขียว–ครีมและระบบสไลด์แนวนอน ปรับหน้าแรกให้พาจากภาพสถานที่ไปสู่การเลือกเมือง รูปแบบการเที่ยว และแนวทางทริป

## สิ่งที่เปลี่ยน

- กริด 6 ช่อง: เวียงจันทน์ วังเวียง หลวงพระบาง หนองเขียว เมืองงอย และสำรวจลาวทั้งหมด หนองเขียว/เมืองงอยเปิดสถานที่ตรงตัว ไม่ต้องค้นหาต่อในแขวง
- ภาพหลัก 14 ภาพเป็นภาพถ่ายจริงทั้งหมด ใช้ภาพที่มีอยู่พร้อมไฟล์หลายขนาดและเครดิตเดิม ปุ่มเล่น/หยุดยังใช้เฉพาะสัญลักษณ์และเล่นทุก 8 วินาที
- เลือกเที่ยว 4 แบบ: ธรรมชาติ เมืองและวัฒนธรรม พักผ่อนริมน้ำ และกิจกรรมกลางแจ้ง เชื่อมกับระบบค้นหาเดิม
- เรื่องราวจากภาพจริง 3 ชุด: ตลาดกลางคืนหลวงพระบาง สายน้ำยามเย็นที่สี่พันดอน และผลกาแฟที่ปากซอง พร้อมลิงก์สถานที่และเครดิตภาพ
- โปรแกรมแนะนำหน้าแรกเหลือ 3 ใบ ไม่มีราคา ส่วนหน้าแพ็กเกจยังครบ 6 โปรแกรมและใช้ราคาตัวอย่างเดิม
- รวมขั้นตอนวางแผนกับส่วนแนะนำ MVM Group และลดส่วนเลือกสถานที่ที่ซ้ำกัน แผนที่เต็มยังใช้งานในหน้าสำรวจลาว
- การ์ดเมืองและหมวดเที่ยวใช้สัดส่วนภาพและตัวอักษรชุดเดียวกัน ส่วนเรื่องราวและโปรแกรมปัดด้านข้างได้บนมือถือ เอฟเฟกต์เล็กและรองรับ reduced motion
- รองรับแสดงทีมจริงสูงสุด 2 คนและรีวิวจริงรายการแรกในหน้าแรกเมื่อเจ้าของเติมข้อมูล ส่วนที่ยังไม่มีข้อมูลจะไม่ปรากฏ ช่องทางติดต่อใช้ค่าจริงจาก `site.contact` ตามเดิม

## ข้อมูลที่ยังรอเจ้าของ

ยังไม่มีรูปทีม รีวิว หรือช่องทางติดต่อจริง จึงไม่มีการเพิ่มข้อมูลสมมุติเป็นข้อมูลบริษัท ระบบเตรียมข้อความสอบถามยังทำงานตามเดิม และเจ้าของสามารถเติม LINE, WhatsApp, โทรศัพท์ หรือช่องทางอื่นใน `dist/content.js` ได้

## ผลตรวจ

- `npm run check` ผ่าน รวมโมดูลใหม่ `home-discovery.js`
- `npm test` ผ่าน 39/39
- `node --test tests/browser/*.test.mjs` ผ่าน 33/33 รวมเคสใหม่ที่ตรวจว่าล้มเหลวก่อนเปลี่ยนหน้าแรก แล้วผ่านหลังเปลี่ยน
- ทดสอบการเปิดเมืองตรงตัว เปลี่ยนภาษา ตัวกรองทั้ง 4 แบบ โปรแกรมละเอียดและแพ็กเกจครบ 6 รายการ สไลด์เปลี่ยนภาพจริง/หยุดจริง การโหลดภาพผิดพลาด และภาพสถานที่ครบ 86 แห่ง
- สร้างเว็บได้ 252 หน้า พร้อม preload และภาพแชร์หน้าแรกที่ตรงกับภาพจริง
- ตัวตรวจ layout ไม่พบรายการแจ้งเตือน
- ภาพตรวจที่ 1440, 768, 390 และ 320 พิกเซล ไม่พบภาพหาย หัวข้อการ์ดล้นแนวนอน หรือข้อผิดพลาด JavaScript
- ความสูงหน้าแรกไทยบน desktop ลดจาก 6,859 เป็น 5,177 พิกเซล (ประมาณ 25%) และมือถือจาก 6,942 เป็น 6,012 พิกเซล (ประมาณ 13%) เมื่อเทียบภาพตรวจรอบก่อน

ภาพตรวจและ metrics อยู่ที่ `.artifacts/home-refresh-2026-10-20/round1/` การตรวจมือถือเป็น Chromium จำลองขนาดจอ ไม่ใช่ผลทดสอบโทรศัพท์จริงทุกเครื่อง
