# ตัวแสดงเมืองแบบภาพวิวเต็มพื้นที่ — 22 ตุลาคม 2026

ปรับการเปิดห้าเมืองบนหน้าแรกตามแนวทาง “ภาพวิวเต็มพื้นที่” ที่ผู้ใช้เลือก: เวียงจันทน์ วังเวียง หลวงพระบาง หนองเขียว และเมืองงอย แทนการ์ดพลิกขนาดเล็กและการ์ดเบลอซ้าย–ขวา

## รูปแบบและการใช้งาน

- คอมพิวเตอร์แสดงภาพถ่ายจริงเต็มพื้นที่กว้างสูงสุด 1120px พร้อมแผงพื้นครีมด้านขวา ภาพยังมองเห็นระหว่างอ่าน ชื่อเมือง คำแนะนำสั้น ไฮไลต์ 3 ข้อ และปุ่มดูรายละเอียดเมืองอยู่รวมกัน
- แสดงช่วงเที่ยวและระยะเวลาจากข้อมูลเดิมเฉพาะเมืองที่มีข้อมูลตรงกัน เวียงจันทน์และหลวงพระบางไม่ใส่เวลาที่คาดเดาหรือยืมระยะเวลาเข้าชมวัดมาแทนทั้งเมือง
- แถบด้านล่างเลือกทั้งห้าเมืองได้โดยตรง มีภาพย่อ ชื่อเมือง และเส้นแสดงเมืองที่เลือก พร้อมลูกศรก่อนหน้า–ถัดไป
- เปลี่ยนภาพด้วย crossfade 280ms หลังภาพใหม่ decode สำเร็จ เก็บภาพเดิมระหว่างโหลด และยกเลิกผลจากคำขอที่เก่ากว่าเมื่อผู้ใช้กดเร็ว ภาพกับข้อมูลจึงเป็นเมืองเดียวกันเสมอ
- ลดการเบลอพื้นหลังเป็น 2px การใช้คีย์บอร์ดและ reduced motion ไม่มีการเลื่อนหรือขยายภาพแบบ spatial transition
- มือถือเรียงภาพเหนือรายละเอียด เลื่อนทั้งตัวแสดงเป็นพื้นที่เดียว ไม่มีช่องเลื่อนข้อความซ้อนด้านใน ปัดแนวนอนบนภาพเพื่อเปลี่ยนเมือง ส่วนข้อความยังเลื่อนแนวตั้งและเลือกข้อความได้ตามปกติ
- ใช้ native dialog ปิดด้วยปุ่ม Escape หรือคลิกพื้นหลัง แล้วคืนโฟกัสและตำแหน่งเลื่อนเดิม การลากเลือกข้อความออกนอกพื้นที่ไม่ทำให้ปิดโดยไม่ตั้งใจ
- ปุ่มดูรายละเอียดระบุชื่อเมืองและเปิดคู่มือฉบับเต็ม ลิงก์วังเวียงแก้ให้เปิดหน้าเมืองจริงโดยตรง การกด Cmd/Ctrl บนลิงก์ยังเปิดแท็บใหม่ได้ตามปกติ
- เครดิตผู้ถ่ายและสัญญาอนุญาตแสดงบนภาพ ข้อความส่วนนี้รองรับไทย ลาว อังกฤษ และจีนตัวย่อ รวมถึงสถานะเมื่อรูปไม่พร้อมแสดง

## ความทนทานที่ตรวจและแก้

หากภาพเริ่มต้นโหลดช้า จะอัปเดตเฉพาะภาพโดยไม่แย่งโฟกัสจากปุ่มหรือเลื่อนคนอ่านกลับขึ้นด้านบน หากภาพโหลดไม่สำเร็จ แสดงข้อความสถานะที่อ่านได้และยังเปิดคู่มือได้

ระหว่างล็อกการเลื่อนหน้า ใช้ตำแหน่งจริงจาก body ที่ตรึงไว้ในการบันทึก history แก้กรณี Back/Forward แล้วกลับมาหน้าแรกที่ตำแหน่งบนสุดแทนตำแหน่งเดิม

## ไฟล์และหลักฐาน

ไฟล์หลักคือ `dist/city-deck.js`, `dist/city-deck.css`, `dist/city-deck-data.js` พร้อมแก้ลิงก์วังเวียงใน `dist/home-discovery.js` และการบันทึกตำแหน่งเลื่อนใน `dist/app.js` ไม่มี dependency เพิ่มเติม

ตรวจไวยากรณ์ผ่าน; unit tests **63/63**; browser tests **77/77** รวมกรณีตัวแสดงเมือง 14 ข้อ สร้าง `build/` ใหม่ครบ 502 หน้า ข้อความสี่ภาษาและการเลือกเมืองมี unit tests 9 ข้อ

ระหว่างทดสอบทั้งเว็บพบการตรวจ Pause/Play เดิมไม่เสถียรจากการรอ 180ms แล้วคาดว่าภาพต้องเดินหน้าเกิน 100ms เสมอ การรันแยกสามครั้งผ่าน จึงเปลี่ยนเฉพาะ test ให้รอการเดินหน้าจริงของ animation ภายใน 2.5 วินาที โดยเก็บเกณฑ์เดิมและการตรวจหยุดค้างไว้ ไม่ได้แก้พฤติกรรมสไลด์ในงานนี้ ผลชุดเต็มหลังปรับ test ผ่าน 77/77
